seanc-has

Check and correct the reading order of automatically transcribed historical pages — make sure the lines are numbered in the order a reader would actually follow, fix any wrong text, and mark each line as checked.

Pick one folder — seanc-has finds the scans and XML inside, pairs them by name, and reopens any work you've already saved.
The sample evaluation set bundled with this app — loads instantly, no file picker.
How this works  ·  3 steps
  1. Open a page — click “Load test documents” below, then click Open next to any page.
  2. Check the reading order — each line is numbered automatically. See if the numbers follow the order a person would actually read the page.
  3. Fix & mark — if the order looks wrong, change the number of columns; correct any text; click each line’s tag to mark it Verified / Corrected / Uncertain; then press Save.
